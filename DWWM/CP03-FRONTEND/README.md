# Structure de base d'un document HTML 

```html
<!DOCTYPE html>
<html lang="fr">
    <head>
        <!-- Les meta informations de la page viennent ici -->
    </head>
    <body>
        <!-- Le contenu de la page vient ici -->
    </body>
</html>
```
