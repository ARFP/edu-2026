## Checklist Qualité Développeur Front-End


### 1 : Validation UI/UX et Écosystème

* [ ] **Fidélité à la maquette :** Les marges, couleurs et typographies respectent la maquette d'origine.
* [ ] **Responsive Design :** L'affichage est correct sur mobile, tablette et écran d'ordinateur.
* [ ] **Connexion API / Données :** Les données s'affichent correctement sans erreur dans la console du navigateur.

---

### 2 : Accessibilité (a11y), SEO et Sécurité

* [ ] **Navigation au clavier :** On peut naviguer dans toute la page avec la touche `Tabulation`.
* [ ] **Images accessibles :** Toutes les images importantes ont un attribut `alt` explicatif.
* [ ] **HTML Sémantique :** Les balises `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>` et les titres (`<h1>` à `<h6>`) sont utilisés au bon endroit.
* [ ] **Contrastes :** Le texte reste lisible et facile à lire par rapport au fond.
* [ ] **Saisie sécurisée :** Les champs de formulaire obligatoire ont les bons attributs (`required`, `type="email"`, etc.).
* [ ] **Sécurité :** Aucun mot de passe ou clé privée n'apparaît en clair dans le code.

---

### 3 : Organisation du Code et Git

* [ ] **Propreté du code :** Le code est indenté, nettoyé et les commentaires inutiles sont supprimés.
* [ ] **Versionning :** Tous les fichiers nécessaires sont enregistrés sur Git avec un message de `commit` clair.
* [ ] **Fichier README :** Un fichier `README.md` explicatif est présent à la racine pour installer et lancer le projet.
